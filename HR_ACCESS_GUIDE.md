# How to Access the HR Intelligence Platform

## From Your Computer (Any HR Team Member)

1. Open any web browser (Chrome, Edge, Firefox)
2. In the address bar, type: **http://<SERVER-IP>:8501**
   - Ask your IT team or the server administrator for the correct IP address
   - Example: `http://192.168.55.65:8501`
3. The dashboard will load automatically — no login required on the app itself

## What You Can Do

| Page | What It's For |
|---|---|
| 📋 Dashboard | Overview of all job postings and candidate counts |
| 🏢 Department Rankings | See top candidates across all roles in a department |
| 📊 Job Rankings | Detailed scores and AI recommendation for each job |
| ⚖️ Compare Candidates | Side-by-side comparison of up to 4 candidates |
| ⏳ Processing Status | Live progress when resumes are being ranked |

## For HR Managers — HR Override

On the Job Rankings page, you can override the AI's recommendation:
- Select a candidate → scroll to "HR Override" → choose Shortlist / Maybe / Reject
- Add a note explaining your decision
- All overrides are logged in the audit trail

## If the Page Won't Load

The server may need to be restarted. Contact IT and ask them to run `START_HR_SYSTEM.bat` on the server computer.
